## Reporting a Vulnerability

please follow these steps to report it responsibly:

### How to Report
1. **Do NOT open a public issue.** Publicly disclosing vulnerabilities puts all users at risk.
2. Send a dm on discord to summersalestart
3. Include as much detail as possible to help me reproduce and address the issue, such as:
   - Type of issue
   - Steps to reproduce the issue
   - Proof of concept code or screenshots (if available)
   - Impact of the issue
